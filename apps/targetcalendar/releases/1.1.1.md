# TargetCalendar Lite 1.1.1

This is a **Lite branding update**. The launcher, round/adaptive launcher and in-app logo now use the green calendar/checkmark with the red LITE ribbon. The installed app name remains TargetCalendar.

Lite's calendar behaviour, daily targets/actuals, local records and **Export to Excel** remain. This update does not add the paid edition's Settings, themes or CSV functionality. It works offline, without an account or network permission, on Android 8.0 (API 26) and later.

## Upgrade from Lite 1.1.0

Compatible 1.1.0 users should keep an Excel export and **install this APK over the existing app**. **Do not uninstall or clear app data to upgrade.** The package `com.ekelola.targetcalendar` and permanent signing identity are unchanged. Earlier 1.1.0 release assets remain available unchanged.

VersionName is **1.1.1**, versionCode **6**. Android upgrade ordering follows versionCode. Code 6 is above previously distributed codes 3 (1.1.0) and 4 (1.2.0), while the separate paid app keeps its independent numbering.

**Existing 1.2.0/RC users: keep your app and CSV exports. Lite 1.1.1 is not your recommended upgrade.** It has the older Lite feature set. No safe 1.2.0-to-Lite migration is claimed, and you should not uninstall, clear records or install Lite over 1.2.0 to change editions.

## Verification

The release metadata records the exact tested APK hash, production certificate, historical Lite source, artwork and reproducible release-tooling ref. The compiled program and non-logo assets match the original public 1.1.0 APK; only artwork, version metadata and release wiring changed. The signed 1.1.0-to-1.1.1 upgrade was checked with disposable blank/zero/ordinary records on Pixel 6a (Android 17/API 37), including restart persistence, calendar behaviour, native Excel save/reopen and coexistence with the separate paid app. These are physical signed-release checks, not Play delivery tests. Other devices, Android versions and OEM launcher masks remain additional coverage.

Download `TargetCalendar-1.1.1.apk` and compare it with `TargetCalendar-1.1.1.apk.sha256`. See `verification.json` and `provenance.json` for metadata. No paid APK, AAB, APK set or private test files are part of this release.
