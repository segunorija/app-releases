# TargetCalendar 1.2.0-rc.1

- Keep the calendar header visible while scrolling; open Settings directly beside Today.
- Save a daily default and explicitly apply it to a selected month, preserving actuals and existing targets unless replacement is confirmed.
- Choose Monday/Sunday week start, Light/Dark/System appearance, and Original green/Ekelola indigo accents.
- Export every saved date to UTF-8 CSV. Validate, preview and confirm CSV imports, with conflicts kept by default and an explicit replacement choice.
- Mark positive actuals against a zero target as purple Overtime. Exclude zero-target/zero-actual days from recorded-day averages while retaining their records.
- Read offline Help, What's new, installed version/build and local data guidance.

Existing records, the daily editor, branding and default light palette are preserved. New installs remain empty. CSV replaces Excel-workbook export and contains records only, not preferences. Native Excel workbooks must be saved as CSV before import.

This is a public testing pre-release. The installed package identifies as version 1.2.0/code 4, following stable 1.1.0/code 3; the distribution tag is `targetcalendar-v1.2.0-rc.1`. The permanent signing identity and application ID remain unchanged. Stable 1.1.0 remains the latest stable download.

The APK is the exact signed/tested artifact from source `3fe989ee3db99a7064f732af0f1696a77c6409a5` and [checks/signing run](https://github.com/segunorija/targetcalendar/actions/runs/42498902288). [PR #4](https://github.com/segunorija/targetcalendar/pull/4) contains the implementation and physical Pixel/Excel/upgrade evidence. Remaining coverage includes Google Sheets, other Android versions, font scaling beyond 1.3 and provider-specific access errors.

APK SHA-256: `90e0a62c54e108ae82613b7cbb610dbc2e23bad0fe679b9e50e917ba3f20df45`.
